# Vishal Singh Chouhan — Full-Stack Developer Portfolio

Premium animated portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Setup

```bash
bun install
bun run dev
```

Open http://localhost:3000.

## Before deployment

1. Put your real resume at `public/resume.pdf`.
2. Replace GitHub and LinkedIn placeholder URLs.
3. Replace the email address.
4. Update project `github` and `live` URLs in `data/projects.ts`.
5. Connect the contact form to an API/email provider.
6. Connect GitHub API if you want live activity data.

## Build

```bash
bun run build
bun run start
```
